## 🚀 Projetos em destaque

### 🎬 Cenaflix

Projeto acadêmico para cadastrar, consultar, editar e excluir filmes, com filtro por categoria. A interface usa Java Swing, e os dados são armazenados no MySQL via JDBC.

[Ver código, imagens e instruções de execução](https://github.com/carolinarope/Java-projetos-academicos/tree/main/Cenaflix_java_jdbc)

### 🗓️ Bela Agenda — Projeto Integrador

Sistema de agendamentos para salões de beleza, criado como Projeto Integrador. Na primeira versão, dá para cadastrar clientes e serviços e organizar horários pelo terminal. Essa versão usa Python e salva os registros em JSON. A próxima etapa do projeto é a versão em Java com MySQL.

[Ver a versão em Python](https://github.com/carolinarope/bela-agenda-python)
